# Language marks

Vector glyphs fetched from [simple-icons](https://simpleicons.org), which is
released under **CC0 1.0 Universal** (public domain). No attribution is required
and the files may be bundled and redistributed freely.

Each file is a single-colour SVG whose `fill` carries the brand colour. The app
reads that fill back and tints the glyph with it, so there is no second table of
brand colours to keep in sync.

uses them only to identify the language of a file.
